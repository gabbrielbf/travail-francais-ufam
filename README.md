# 🏳️ 🇫🇷 La France

C'est un projet fait en Python pour un travail de français à l'UFAM. C'est un outil interactif avec des textes simples pour apprendre des trucs sur la France, avec des liens pour des images et des vidéos à la fin.

  <img src="assets/la_france.jpg" alt="La France Banner" width="460">
</p>

---

## 🛠️ Comment ça marche ?

* **`src/app.py`**: C'est le fichier principal qui lance le menu et gère l'application.
* **`src/lessons.py`**: C'est là qu'on a mis tous les textes, les leçons et les liens pour les vidéos et images.
* **`src/utils.py`**: Des petits outils pour aider le code, par exemple pour éviter les erreurs d'affichage.
